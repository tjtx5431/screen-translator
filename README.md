# 屏幕翻译（ScreenTranslator）

按一下快捷键，框住屏幕上任意一块英文，旁边立刻弹出中文译文卡片。不用复制、不用切窗口、不用装任何东西。

- **OCR 走 Windows 自带引擎**，离线、免费、零安装
- **翻译走免费公开接口**（有道 / Google / MyMemory 依次重试），不消耗你自己的 API 额度
- 单个 PowerShell 脚本，没有依赖，不写注册表，**不开机自启**

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| PowerShell | Windows PowerShell 5.1（系统自带。**不支持 PowerShell 7**，WinRT OCR 在 PS7 里用不了） |
| OCR 语言包 | 需要 **en-US**（英语）。中文系统若没装，见下方「常见问题」 |

## 用法

1. 双击 `启动 屏幕翻译.lnk`。屏幕右下角出现一个绿色小图标，程序在后台待命。
2. 看到不认识的英文时，按 **`Ctrl + Alt + Z`**。
3. 整个屏幕变暗、鼠标变十字后，**拖拽框住**要翻译的区域。
4. 松手，选框旁边弹出卡片：上面是中文译文，下面是识别出的原文。
5. 按 `Esc` 或点卡片外面任意位置即可收起。想留着就点「复制译文」。

**取消框选**：拖拽过程中按 `Esc` 或点鼠标右键。

托盘图标右键菜单：

- **立即划词翻译** —— 相当于按一次热键（热键被别的软件占用时用这个）
- **使用说明** —— 弹出操作提示
- **退出**

## 常用调整

用记事本打开 `ScreenTranslator.ps1`，开头十几行就是全部配置：

| 变量 | 作用 |
| --- | --- |
| `$HotkeyMods` / `$HotkeyKey` / `$HotkeyName` | 换快捷键。三个要一起改，`$HotkeyName` 只是显示用的文字 |
| `$TranslateTimeout` | 翻译接口超时秒数，网络差可以调大 |
| `$BaseCardW` / `$BaseCardMaxBody` | 卡片宽度 / 正文最大高度（单位是 96 DPI 下的像素，会自动按你的缩放比例放大） |

改完存盘**必须保持 UTF-8 带 BOM 编码**，否则中文会变乱码。然后在托盘菜单里「退出」再重新双击快捷方式。

## ⚠️ 隐私提醒

**识别出来的屏幕文字会通过网络发送到第三方免费翻译服务**（有道、Google、MyMemory）。

请不要用它翻译密码、密钥、身份证号、公司内部资料等敏感内容。OCR 本身是本机离线完成的，但翻译这一步必须联网。

## 常见问题

**按热键没反应**
快捷键可能被别的程序（截图工具、输入法、录屏软件）抢走了。程序启动时会检测，被占用会弹气泡提示；此时右键托盘图标选「立即划词翻译」照样能用。也可以自己换个快捷键。

**右下角找不到托盘图标**
Windows 11 默认会把新图标折叠进 `^` 小三角里。把它拖到任务栏上即可固定；或者
`设置 → 个性化 → 任务栏 → 其他系统托盘图标` 里打开。

**提示「没有识别到文字」**
- 框选区域里确实没有文字，或文字太小/太糊。**把画面放大一点再框**（浏览器按 `Ctrl` + `+`），识别率会明显提高。
- 如果所有区域都识别不出来，多半是**没装英语 OCR 语言包**：
  `设置 → 时间和语言 → 语言和区域 → 添加语言 → English (United States)`，
  勾选「可选语言功能 → 光学字符识别」，装完重启本程序。

**提示「所有翻译接口都失败了」**
免费接口不稳定，可能被限流或临时失效。过一会儿再试；如果长期不行，说明接口挂了，需要换一个（改 `Invoke-YoudaoTranslate` 里的 URL 即可）。卡片里仍会显示已经识别出来的原文。

**卡片只显示了一部分，下面的字看不见**
卡片正文可以**滚动**（鼠标滚轮），右侧有滚动条。也可以直接点「复制译文」粘到别处看。

## 已知限制

- 只能识别**屏幕上看得见的文字**，识别不了图片里的艺术字、竖排文字、验证码。
- 原文会**保留它原本的换行**（因为 OCR 是按行识别的），所以从网页上框一大段话时，原文区会跟着原来的折行，看起来有点参差——译文不受影响。
- 免费接口是非官方的，**随时可能失效**。
- 每次识别都要重新截图，视频字幕这类不断变化的画面建议暂停后再框。
